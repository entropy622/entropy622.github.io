# 莱茵生命风格规范

博客用于技术笔记、日常和作品展示。风格取自莱茵生命官方美术：做旧的聚酯白、柔和的黑、机械操作橙、生态绿，直角，几何宽体字，黑底白字铭牌。目标是"研究所档案"的克制感，信息优先，装饰退后。

## 设计原则

1. **克制优先。** 每屏只保留一个视觉焦点。装饰只能出现在留白处，不能压在标题、正文或卡片上。拿不准就删。
2. **背景只做纸面。** 全站背景只有淡方格纸、左侧刻度尺和四角框线。不要再放大号 logo、辅助圆、坐标轴、十字准星或散落的测量标注，它们会穿过内容，干扰阅读。
3. **文字标签要有信息量。** 不加 "PERSONAL PERSPECTIVE / AE-01" 这类纯装饰编号。等宽小字只用于真实元数据（日期、阅读时长、分区、页码）。
4. **头像装饰保持简洁。** 只用一条开口圆弧、一圈虚线圆、一个墨色卫星点和两个橙点（`RhineOrbit.astro`）。不加读数、刻度环或多层轨道。
5. **列表要有明确分界。** 文章列表用独立卡片：纸面底色、细边框、卡片间距约 1.1rem、左侧常驻 3px 分区色条。不用细分隔线把行挤在一起。
6. **时间信息规整排列。** 日期统一写成 `YYYY.MM.DD`，放在元信息行最前面。不要把"日"单独放大，那样从上往下看没有规律。
7. **封面图做背景。** 博客条目的封面铺在卡片右侧约 50% 的位置，从左向右渐显（mask），透明度 0.35，hover 时升到 0.7。手机端改为顶部铺图，向下渐隐。
8. **开屏动画保留。** `OpeningSequence.astro` 是用户认可的部分，不随样式调整改动。

## Token（`src/assets/styles/rhine.css`）

新样式一律引用变量，不写死颜色。

| 变量 | 用途 |
|---|---|
| `--rl-paper` / `--rl-sheet` / `--rl-sheet-2` | 页面底色 / 卡片与文档纸面 / 次级面 |
| `--rl-ink` / `--rl-inverse` | 主墨色 / 反色（铭牌文字） |
| `--rl-accent` / `--rl-accent-ink` | 橙色强调（色块、色条）/ 橙色文字和链接 hover |
| `--rl-green` / `--rl-green-ink` | 状态点、"日常"分区 |
| `--rl-line` / `--rl-line-strong` | 细分隔 / 边框 |
| `--rl-shadow`, `--rl-glass`, `--rl-grid` | 卡片阴影、吸顶毛玻璃、方格纸线 |
| `--rl-display` / `--rl-sans` / `--rl-mono` | 标题宽体 / 正文 / 元数据 |
| `--rl-ease` | 统一缓动 `cubic-bezier(.22,1,.36,1)` |

- 明暗两套值都在 `rhine.css` 中定义（`:root` 与 `html.dark`），新增变量必须同时给出暗色值。
- 字体为自托管 Archivo Variable（宽体标题用 `font-stretch: 125%`，替代 Novecento Wide）、JetBrains Mono Variable、Noto Sans SC Variable。新增字体需要放 OFL 许可到 `public/licenses/`。
- `--radius: 0px`，全站直角。不使用圆角，圆形只用于头像和状态点。

## 版式原语

优先复用，不要另造一套：

- `.rl-display`：宽体大写标题。
- `.rl-kicker`：等宽小标题，前面带橙色方块。
- `.rl-plate`：黑底白字铭牌，用于中文副标题。
- `.rl-rule`：带橙色起始段的分隔线。
- `.rl-panel` / `.rl-sheet`：带左上橙角的面板 / 文章纸面。
- `.rl-chip.is-tech` / `.rl-chip.is-daily`：分区标签。
- `.rl-btn` / `.rl-btn.is-solid`：按钮，实心版切一个角。
- `.rl-status`：绿色状态点。

强调色的分配：橙色用于"技术笔记"和交互反馈，绿色用于"日常"和在线状态，墨色用于"作品"。

## 页面结构

- **首页**（`src/pages/index.astro` + `home-dossier.css`）依次为：
  - Hero：大标题 AENTRO、"回首空城"铭牌、简介、两个按钮，右侧头像。
  - 四格信息条和终端条。
  - "档案索引"：技术笔记、日常、作品三张分区卡。
  - 精选作品。
- **博客列表**由 `src/components/blog/PostEntry.astro` 渲染，`blog/[...page].astro` 和 `tags/[tag]/[...page].astro` 共用这个组件。分区由 `src/utils/blog.ts` 的 `TECH_TAGS` 按标签判定。
- **文章页**：正文放在 `.rl-sheet` 纸面上。h2 带细线和橙色方块，h3 前缀 `// `，代码块用纸面底色加墨色顶边。阅读时 HUD 状态文字隐藏，Live2D 下沉半透明。
- **标题容器**：Hero 和页脚超大字使用 `container-type: inline-size`，字号用 `cqi`，避免溢出或撞到右侧元素。
- **页面滚动条**：8px、直角、半透明墨色滑块，hover 时变橙。

## 校验

1. `npm run build`（包含 `astro check`），要求 0 error。
2. 在 `npm run dev` 的实际页面检查首页、`/blog`、一篇文章页，分别看亮色、暗色和 390px 宽度。
3. 确认装饰没有压到文字，列表条目边界清晰，没有横向溢出。

## 已否决的做法

- 背景大号莱茵 logo 线框和辅助几何（干扰阅读）。
- 头像周围的多层轨道、刻度和读数（太花）。
- 列表左侧放大的"日"数字（无规律、显乱）。
- 列表只用细线分隔（条目挤在一起）。
- 封面缩成右侧灰度小图（用户偏好整幅渐显背景）。
